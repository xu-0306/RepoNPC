# Noto Sans CJK TC

`NotoSansCJKtc-Regular.otf` is the upstream Traditional Chinese regional OTF
from `notofonts/noto-cjk` and is used only at build time to produce deterministic
PNG/GIF README cards. SVG output contains text but no embedded or remote font.
