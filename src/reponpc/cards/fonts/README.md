# README card fonts

The bundled fonts produce deterministic hard-edged PNG/GIF text. SVG output
contains lossless pixel paths of the first frame, with no text or font dependency.

## Noto Sans CJK TC

`NotoSansCJKtc-Regular.otf` is the upstream Traditional Chinese regional OTF
from `notofonts/noto-cjk`. It renders non-Latin names and all body text.

- Upstream: `https://github.com/notofonts/noto-cjk`
- Source path: `Sans/OTF/TraditionalChinese/NotoSansCJKtc-Regular.otf`
- SHA-256: `dce08bd4fd91aa8aa76ed8fea4b694c2dfb8550f67871e326843212ddbeb88b4`
- License: SIL Open Font License 1.1 in `OFL.txt`

## Press Start 2P

`press-start-2p-latin-400-normal.woff2` is the unmodified Latin subset used for
Latin-only display names at 16 px. Copied byte-for-byte from the existing web
asset; no download or font conversion is needed.

- Source: `apps/web/src/assets/fonts/press-start-2p-latin-400-normal.woff2`
- Upstream package: `@fontsource/press-start-2p` 5.3.0
- SHA-256: `afec86997fdaf54af1f59358fa2c1e2a0f1d04146edad18e5cd141d0384a7548`
- License: SIL Open Font License 1.1 in `PressStart2P-OFL.txt`, copied from
  `apps/web/src/assets/fonts/OFL.txt`
